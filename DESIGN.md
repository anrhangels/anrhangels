# Оформление профиля

Собственная графика на основе пиксельной подписи anrhangels: тёмный терминал, белые объёмные буквы, тонкие разделители и спокойные подписи. Цвет используется только для трёх кнопок окна и статусов проектов. Графика, тексты и композиция созданы для этого профиля; чужие изображения не включены.

Все отображаемые файлы находятся в репозитории, внешние генераторы статистики и сервисы изображений не используются. Для чтения предусмотрены alt-тексты и раскрывающаяся текстовая версия. Карточки проектов ведут в соответствующие публичные репозитории.

Редактируемый источник — `assets/create_art.py`, результаты — PNG и SVG. Для пересборки нужны Python 3, pycairo и шрифты DejaVu. Из корня: `python3 assets/create_art.py`. На GitHub эти зависимости не нужны.

`preview.html` — локальный макет раскладки. Настоящий README отображается средствами GitHub, поэтому точные отступы могут отличаться.

Для профиля необходим публичный репозиторий `anrhangels/anrhangels` с `README.md` в корне. GitHub Pages для этого не требуется.

Discord: `anrhangels`. Публичный адрес электронной почты и персональные данные в оформление не включены.
